# Elementa demo

Cinematic scroll site for Elementa, a one-room cantilevered cabin in Rawdon, Québec.

- `site/` – the deployable static site (serve the folder with any static server; see `site/README.md`)
- `0905.mov` – the hero film; `dji_*.MOV`, `hf_*.mp4`, `IMG_*.JPG`, `*.jpeg` – original footage, phone photos and brand element images
- `generated/` – fal.ai outputs (Kling / Seedance shots and bridges, Seedream edits, Topaz 4K masters) and earlier site versions
- `bedroom_film/` – bedroom film experiments

The 167 MB 4K hero master and the regenerable frame caches are not in the repo (see `.gitignore`).
